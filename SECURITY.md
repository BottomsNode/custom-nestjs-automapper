# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| `@nestjs-automapper/*` 2.x | Yes |
| `custom-automapper` 1.x | No |

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/nishit-shivdasani/nestjs-automapper/security/advisories/new),
not in a public issue. Include the affected package and version, and a
minimal reproduction if you have one.
